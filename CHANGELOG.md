# Changelog

All notable changes to Switchyard will be documented in this file.

## [1.0.0] - 2026-10-11
### Added
- Initial production-grade release of Switchyard.
- Provider-agnostic LLM integration with Ollama default and cloud failover.
- RFC 7807 compliant structured error handling.
- Full multi-tenant authentication (Argon2id + JWT + Scoped API Keys).
- Async SQLAlchemy 2 persistence with Alembic migrations.
- Celery worker orchestration over Redis.
- React 19 frontend with Tailwind CSS v4 and distinct design archetype.
- Complete evaluation runner with reproducible metrics.
- Comprehensive MkDocs technical documentation suite.
